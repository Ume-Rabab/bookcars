# Pakistan Localization

SafarRent defaults are configuration-driven: PKR, `Asia/Karachi`, Pakistan (`PK`), Pakistan map coordinates, and English-first labels. Environment examples are provided for backend, admin, and frontend. Internal package and API identifiers remain unchanged for compatibility.

Future additions should keep locations, airports, payment methods, Urdu labels, and phone validation in configuration or shared validation helpers rather than unrelated business logic.
